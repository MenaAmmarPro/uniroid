# Uniroid dedicated website — plan

## Goal
Create a separate marketing/landing website for the Uniroid Android app (distinct from the hub site), hosted on GitHub Pages, matching the existing MenaAmmarPro aesthetic.

## Tech stack (recommended)
- Static site: HTML5 + CSS3 + vanilla JS (consistent with menaammarpro.github.io).
- Hosted via GitHub Pages on repo `MenaAmmarPro/uniroid-site` (or `uniroid-web`).
- No build step; optional small JS for theme toggle, release banner, lightbox.
- Reuse existing theme.css patterns and starfield effect.

## Site overview / pages
- `index.html`: single-page landing with sections:
  1. Hero: app name, tagline "our little world in one app", download APK button (latest), source link, version badge.
  2. Features grid: tools, games, Us content (mirroring README).
  3. Screenshots carousel (manual images from app).
  4. How it works: offline, shared_preferences, auto-update.
  5. Changelog: feed.json releases rendered.
  6. Download/Install guide: allow unknown sources, auto-update note.
  7. Footer: links to hub site, GitHub, license.

## UI direction
- White-forward pink theme (app's theme), dark mode toggle (like hub).
- Card-based feature grid, rounded corners, soft shadows.
- Mobile-first responsive; max-width container ~1100px.
- App icon (assets/icons/uniroid.png) as logo.

## Assets needed
- Screenshots (5-8) of app pages.
- App icon already in hub assets (copy).
- Optional OG image.

## Data flow
- Download button -> GitHub releases latest APK.
- Changelog fetched from feed.json at runtime (optional) or baked.

## Validation
- Lighthouse mobile score > 90.
- Links resolve (APK, source, hub).
- Responsive on 360px-1440px.
